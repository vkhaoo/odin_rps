# odin_rps

During this small project I've put into action everything I've learned through Codewars and Odin Project. This helped me understand how to deal with rethorically small logic problems and how to approach them.

The part that I personally found the hardest was most likely the one over maps/objects.
As easy as they may seem, it's the first time I have to deal with them in an actual code program. They weren't actually hard, it was actually fun to learn how to get along with them and start a foundation for their basic use.
To approach them, I made sure to use every information I had previously from other experiences and mixed it with some information online about their syntax and their methods.

It was overall a fun project, which I personally think I'll go back to whenever I'll get the chance.
